# Contributing

Thanks for contributing to Hugents.

## Scope

This repository is currently a documentation and structure scaffold. Keep contributions focused, project-agnostic, and compatible with the security policy.

## Before opening a pull request

- Confirm no secrets are present.
- Confirm no real target URLs are present.
- Confirm no real user or player data is present.
- Update documentation when behavior or design decisions change.

## Contribution style

- Prefer small, focused pull requests.
- Keep language clear and concise.
- Do not add runnable application code until roadmap phases introduce implementation.

## Security

Read and follow `SECURITY.md` and `docs/security.md`.
